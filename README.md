# إدارة أعمال المستقبل

تطبيق إدارة مستقل React/TypeScript/Vite، مع خادم Convex مشترك مع تطبيق التاجر وصلاحيات تفرض على الخادم.

## التشغيل

```sh
npm ci
npm run dev -- --port 5182
npm run build
npm run lint
npx vitest run tests/backend.test.ts
```

حدد VITE_CONVEX_URL وVITE_SENTRY_DSN في ملفات البيئة المحلية؛ لا ترفعها. أسماء متغيرات الخادم: ADMIN_PASSWORD_HASH وADMIN_PASSWORD_SALT (PBKDF2-SHA256150000، الملح والمشتق hex). رمز الإدارة لا يوجد في حزمة المتصفح. رمز تأكيد الحذف101 ليس بديلًا عن جلسة الإدارة.

## السلوك

- بيانات وكلمات مرور التجار محفوظة في Convex. القائمة العامة للإدارة لا ترجع كلمة المرور أو مشتقها أو الملح.
- تجميد الحساب يمنع دخوله. انتهاء الاشتراك يسمح بالقراءة ويمنع الكتابة فورًا. المتأخرون بعد24ساعة، مهلة3أيام للمتابعة فقط.
- تغيير مدة الاشتراك أو تحديد التجديد يبدأ مدة جديدة من الحفظ؛ تعديل الاسم فقط يحافظ على الانتهاء.
- الحذف يوقف الحساب فورًا، ويمحو سجلاته على دفعات. يحتفظ الخادم مؤقتًا ببصمة الجلسة فقط لإبلاغ الأجهزة بالحذف. الجهاز غير المتصل يعلم بالحذف عند اتصاله، ولا يمكن محو نسخة غير متصلة عن بُعد فورًا.
- الأدمن يحتاج الإنترنت. اسم المستودع العشوائي ليس حماية؛ التحقق من الصلاحيات يتم على الخادم.
